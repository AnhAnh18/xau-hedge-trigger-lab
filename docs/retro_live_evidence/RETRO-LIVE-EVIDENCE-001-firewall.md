# RETRO-LIVE-EVIDENCE-001 Firewall

E-001 is governance-only and synthetic-only.

Forbidden inputs and surfaces: raw trading rows, credentials, private paths,
journals, deals, fees, swaps, profits, tickets, terminal caches, `.ex5`, M5
manifests/models/outcomes/frozen artifacts, realtime network feeds, MT5 APIs,
order submission, demo, canary, and live execution.

Allowed retained outputs: generated aliases, object hashes, schema versions,
redacted counts, gate results, synthetic aggregates, and canonical digests.
Oracle observations are diagnostic-only and cannot affect policy, accounting,
fold selection, candidate ranking, thresholds, or state transitions.
