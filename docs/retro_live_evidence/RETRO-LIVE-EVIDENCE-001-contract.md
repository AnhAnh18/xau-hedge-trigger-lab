# RETRO-LIVE-EVIDENCE-001 Contract

Status: owner-approved protocol work only; no new source access or execution
authorization. This milestone is independent of M5 and RB-020.

## Objective

Freeze the evidence protocol for a future actionful observation block. E-001
uses synthetic fixtures only and produces no historical result.

## Claims and exclusions

Future reports may describe behavioral parity, coverage, timing, state safety,
robustness, and accounting conservation. They may not claim profitability,
broker ownership, clone status, live suitability, or execution safety before
all later gates pass. E-001 does not authorize realtime feeds, order APIs,
demo, canary, or live trading.

## Source boundary

No source is opened in E-001. E-002 requires a new owner authorization naming
the exact aliases, hashes, UTC window, allowed fields, retention, and parser
version. Existing M5 and RETRO receipts are not inherited automatically.

## Gate authority

The immutable machine-readable gate registry is
`RETRO-LIVE-EVIDENCE-001-gates.json`. Its formulas, thresholds, categories,
timezone policy, holdout protocol, and result taxonomy are frozen before E-002
inspection. Missing denominators are `not-evaluable`, never passing zeros.

## Stop conditions

Stop on missing authorization, source expansion, hash/window/field mismatch,
timezone ambiguity, lookahead or oracle leakage, raw/privacy exposure, M5
contamination, nondeterminism, unsafe state transition, or any request to send
an order.
